このプロジェクトでは、HTML・CSS・JavaScript を用いてインタラクティブなフロントエンドを構築し、Firebase によってデプロイを行いました。JavaScript による動的処理やレスポンシブデザインの対応、また .gitignore・firebase.json・.firebaserc などの構成ファイルも正しく設定し、再現性のあるプロジェクト管理を意識しました。
主な機能は以下の通りです：
1マップ上にマーカーをドラッグ＆ドロップして配置可能
2アイコンパネルから自由に選択・操作
3ユーザー間でマップ変更がリアルタイムに反映
4マウスによるズーム・右クリックドラッグによるスクロール操作

この経験を通じて、Web 開発の一連の流れを実践的に学び、自走力・問題解決力を高めることができました。今後はチーム開発の中でも、積極的に貢献できると確信しています。
